# Léxico português brasileiro (pt-BR)

Fonte: [fserb/pt-br](https://github.com/fserb/pt-br), arquivo `lexico`.
- Snapshot fixado no commit `93ba2a6f3b2f85262fba72df09d448c6bb2fa50a` (2025-08-08).
- 145.744 entradas lexicais.
- Arquivos numerados em ordem alfabética e concatenados para formar o vocabulário de validação.
- Uso: verificar palavras e segmentar tokens concatenados antes de aceitar enunciados/alternativas. O dicionário não corrige conteúdo por si só; se a segmentação tiver mais de uma interpretação, a questão deve ir para revisão.
